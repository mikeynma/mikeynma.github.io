How to play them

On the Next

Each game is a .nex file (Hex Appeal comes in a folder with the files it reads beside it: copy the whole folder). On a ZX Spectrum Next, copy it to your SD card, pick it in the Browser and press ENTER. On a computer, open it in the CSpect emulator.

On the original Spectrum

Each game and demo comes as tapes: .tzx and .tap files, a 48K one and a 128K one where they differ. Open them in an emulator such as ZX Spin, Fuse or Retro Virtual Machine, or play the .tzx into a real Spectrum from a TZX player. Many of them load with our own tape loaders, which need the tape played in real time: switch off instant and fast loading. Each page says which file is which.

They're free, and always will be.
